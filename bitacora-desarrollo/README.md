# Bitácora de desarrollo / 开发日志

Registro diario del avance del proyecto. / 项目进展的每日记录。

## Reglas / 规则

- Un archivo por día con nombre `AAAA-MM-DD.md`. / 每天一个文件，命名 `AAAA-MM-DD.md`（年-月-日）。
- Al terminar cada sesión de desarrollo, se registra lo **completado** y lo **pendiente**. / 每次开发结束，记录**已完成**与**待办**。
- Bilingüe: español + 中文. / 双语：西班牙语 + 中文。
- La IA (Claude / Copilot) actualiza la bitácora automáticamente al final de cada sesión. / AI 助手在每次会话结束时自动更新日志。

## Plantilla / 模板

```markdown
# AAAA-MM-DD

## Fase actual / 当前阶段
(p. ej. Fase 0 — Cimientos)

## Completado hoy / 今日完成
- ...

## Pendiente / 待办
- [ ] ...

## Notas / 备注
- ...
```
