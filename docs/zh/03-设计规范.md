# 03 — 设计规范（UI/UX）

设计以**简洁、直观**为主。默认西班牙语。360 px 起响应式。无障碍达 WCAG 2.1 AA。

> 与 [docs/es/03-guia-diseno.md](../es/03-guia-diseno.md) 对应。

## 1. 配色方案

| 角色 | 颜色 | 建议 HEX | 用途 |
|---|---|---|---|
| 主色（绿） | 绿色 | `#2E7D32` / 亮 `#43A047` | 主要操作、品牌、成功 |
| 辅色（黄/橙） | 琥珀/橙 | `#F9A825` / `#FB8C00` | 提醒、强调、临期预警 |
| 底色（白/灰） | 白/灰 | `#FFFFFF` / `#F5F5F5` / `#E0E0E0` | 背景、卡片、边框 |
| 控件（深蓝） | 深蓝 | `#0D47A1` / `#1A237E` | 链接、控件、细节 |
| 文字 | 深灰 | `#212121` / 次要 `#616161` | 可读性 |
| 状态 | 成功 `#2E7D32`·提醒 `#F9A825`·错误 `#C62828`·信息 `#0D47A1` | | 反馈 |

## 2. 字体与间距
- 系统无衬线字体：易读且快。基准字号 16 px。
- 间距用 8 px 的倍数。
- 圆角 8 px；卡片用柔和阴影。

## 3. 基础组件
- **按钮**：主要（绿色填充）、次要（描边）、危险（红色）。hover/focus 状态明显。
- **表单**：西语清晰标签，错误提示在字段下方，实时校验。
- **表格**：FEFO 库存中，临期（≤ 3 天）批次用琥珀色高亮。
- **提醒/通知**：按状态着色；图标 + 文字。
- **卡片**：用于面板摘要（救助公斤数、有效率）。

## 4. 响应式
- 移动优先，360 px 起。
- 断点：手机 < 600，平板 600–1024，桌面 > 1024。
- 手机端侧边菜单可折叠。

## 5. 无障碍（WCAG 2.1 AA）
- 文字对比度 ≥ 4.5:1。
- 所有字段配 `<label>`；支持键盘导航；焦点可见。
- 图片带 `alt`；装饰性图标用 `aria-hidden`。
- 用 **axe-core** 验证（目标 ≥ 90% 页面）。

## 6. 语言（i18n）
- 默认西语；文案用 `react-i18next` 管理（JSX 中不写死文字）。
- 结构预留英语（翻译键放 `src/i18n/`）。

## 7. 图标
- 一致、轻量的图标集（如 lucide-react 或自制 SVG）。
- 语义化图标：捐赠、库存、临期预警、地图、报表。
