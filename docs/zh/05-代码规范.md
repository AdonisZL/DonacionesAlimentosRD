# 05 — 代码规范

**核心规则：代码用西班牙语编写。** 语言关键字与库名保留英文（不翻译）。

> 与 [docs/es/05-estandares-codigo.md](../es/05-estandares-codigo.md) 对应。

## 1. 代码语言
- **西班牙语**：变量、函数、类、方法、API 路径、自建文件/文件夹名、提交信息、注释。
- **英语（保留）**：语言语法、库及其 API（`FastAPI`、`useState`、`select` 等）。
- 注释以西语为主；必要时可加简短中文帮助用户理解。

## 2. 命名规范

### 后端（Python — PEP 8）
- 变量与函数：西语 `snake_case` → `crear_usuario`、`calcular_ventana_donacion`、`fecha_vencimiento`。
- 类：西语 `PascalCase` → `LoteInventario`、`ServicioEmparejamiento`。
- 常量：`MAYUSCULAS_CON_GUION_BAJO` → `RADIO_MAXIMO_KM`。
- 文件/模块：`snake_case` → `servicio_inventario.py`、`router_usuarios.py`。
- API 路径：西语、复数 → `/api/usuarios`、`/api/lotes`、`/api/emparejamientos`。

### 前端（React — JavaScript）
- 组件：西语 `PascalCase` → `FormularioRegistro.jsx`、`TablaInventario.jsx`。
- 变量/函数：西语 `camelCase` → `usuarioActual`、`cargarLotes()`。
- 自定义 Hook：`useSesion`、`useInventario`。
- 用户可见文案：一律走 i18n（JSX 不写死文字）。

## 3. 结构与风格
- **后端**：职责分离 → `routers`（HTTP）调用 `services`（逻辑），`services` 用 `models`（数据）；`schemas` 校验输入/输出。
- 用 Python 类型注解与 Pydantic 类型。路由中不写业务逻辑。
- **前端**：组件小而可复用；HTTP 调用集中在 `src/api/`。
- 代码中不放凭证或密钥 URL：后端用 `.env`，前端用 Vite 变量（`import.meta.env`）。

## 4. 错误处理
- 后端：返回正确的 HTTP 状态码（400、401、403、404、409、422、500），并给出清晰的西语信息。
- 在系统边界（API 入口、表单）校验。不做多余的内部校验。

## 5. 提交信息（约定式，西语）
格式：`tipo: descripción breve`。
- `feat: registrar donante formalizado`
- `fix: corregir cálculo de ventana FEFO`
- `docs: actualizar guía de diseño`
- `test: pruebas de autenticación`
- `refactor:`、`chore:`、`style:`。

## 6. 测试
- 后端：`pytest`。前端：`Vitest`。
- 目标（RNF-16）：单元覆盖 ≥ 80%，集成 ≥ 60%。
- 测试命名用西语：`test_rechaza_lote_vencido`。

## 7. 质量
- 后端格式化：`black` + `isort`；lint：`ruff`/`flake8`。
- 前端 lint：`oxlint`（已有）。
- 模块化（轻量 DDD），低耦合（RNF-17）。
