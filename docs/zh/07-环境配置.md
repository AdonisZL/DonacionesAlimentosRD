# 07 — 环境配置

在新电脑上跑起来项目的指南（供团队使用）。

> 与 [docs/es/07-configuracion-entorno.md](../es/07-configuracion-entorno.md) 对应。

## 1. 前置软件

| 工具 | 版本 | 说明 |
|---|---|---|
| Python | 3.11+ | 含 `pip` 与 `venv` |
| Node.js | 18+（用 22.14 测试） | 含 `npm` |
| PostgreSQL | 18 | 含 **PostGIS** 扩展 |
| Git | 任意 | 用于克隆仓库 |

检查版本：
```powershell
python --version
node --version
& 'C:\Program Files\PostgreSQL\18\bin\psql.exe' --version
```

## 2. 数据库（PostgreSQL + PostGIS）

1. 用官方安装包安装 **PostgreSQL 18**。
2. 安装时会设置 `postgres` 用户密码：**记住它**。
3. 结束时打开 **Stack Builder**，安装 **PostGIS**（*Spatial Extensions* 分类）。
4. 确认扩展文件存在：
   ```powershell
   Test-Path 'C:\Program Files\PostgreSQL\18\share\extension\postgis.control'
   Test-Path 'C:\Program Files\PostgreSQL\18\share\extension\uuid-ossp.control'
   ```
   两者都应返回 `True`。

> 不需要手动建库：脚本 `scripts/inicializar_bd.py` 会自动创建。

## 3. 后端（FastAPI）

```powershell
cd backend
python -m venv venv                                   # 仅首次
.\venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```
编辑 `backend\.env`，把真实密码填入 `BD_CONTRASENA`。

初始化数据库（建库、22 张表、种子数据）：
```powershell
.\venv\Scripts\python.exe scripts\inicializar_bd.py
.\venv\Scripts\python.exe scripts\verificar_bd.py     # 可选：检查状态
```

创建管理员用户（**初始化后必须执行**）：
```powershell
.\venv\Scripts\python.exe scripts\crear_admin.py
```
> 默认管理员：`admin.demo@ejemplo.com` / `AdminRD2026!`。
> 生产环境**务必修改**默认密码。管理员角色不能通过 API 自助注册（RF-28）。

（可选）插入演示数据以测试功能：
```powershell
.\venv\Scripts\python.exe scripts\datos_demo.py
```
> 需先启动 API（`uvicorn`）。创建演示用户、产品、批次与匹配记录。

启动 API：
```powershell
.\venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
```

### 后端依赖

## 4. 前端（React + Vite）

```powershell
cd frontend
npm install
npm run dev
```
应用在 http://localhost:5173，与 http://127.0.0.1:8000 的 API 通信。

### 前端环境变量
前端通过 `VITE_URL_API` 变量指定后端 API 地址，默认 `http://127.0.0.1:8000`。
如需修改，创建 `frontend\.env`：
```
VITE_URL_API=http://127.0.0.1:8000
```
> 若后端运行在其他端口或主机上，修改此变量即可。

### 字体与图标（网络依赖）
前端使用 **Google Fonts**（Hanken Grotesk + Inter）和 **Material Symbols** 图标字体。
首次加载需要网络连接。若在离线环境开发，字体将回退到系统默认字体，不影响功能。

> `frontend\.env.example` 已包含 `VITE_URL_API` 模板及其默认值，如需修改请复制为 `.env`。

## 5. 环境变量

### 后端环境变量 (`.env`)

`backend/.env`（基于 `.env.example`）：

| 变量 | 说明 | 示例 |
|---|---|---|
| `BD_HOST` | PostgreSQL 主机 | `localhost` |
| `BD_PUERTO` | PostgreSQL 端口 | `5432` |
| `BD_NOMBRE` | 数据库名称 | `donaciones_alimentos` |
| `BD_USUARIO` | 数据库用户 | `postgres` |
| `BD_CONTRASENA` | 数据库密码 | `tu_contraseña_de_postgres` |
| `JWT_SECRETO` | JWT 签名密钥 | `una_clave_larga_aleatoria_y_secreta` |
| `JWT_ALGORITMO` | JWT 签名算法 | `HS256` |
| `JWT_MINUTOS_EXPIRACION` | JWT 过期时间（分钟） | `60` |

⚠️ **安全警告**：
- **`JWT_SECRETO`** 在生产环境**必须**更换为长随机字符串（可用 `openssl rand -hex 32` 生成）。
- 切勿把 `.env` 提交到仓库（已在 `.gitignore` 中忽略）。
- 管理员默认密码 `AdminRD2026!` 在生产环境**务必修改**。

### 前端环境变量 (`frontend/.env`)

| 变量 | 说明 | 默认值 |
|---|---|---|
| `VITE_URL_API` | 后端 API 基础地址 | `http://127.0.0.1:8000` |

## 7. PostgreSQL 服务管理

PostgreSQL 作为 Windows 服务运行，检查状态：
```powershell
Get-Service -Name "postgresql-x64-18" | Select-Object Status,StartType
```
如果未运行，启动服务：
```powershell
Start-Service -Name "postgresql-x64-18"
```
> 需要**管理员权限**启动/停止服务。建议设置为自动启动：`Set-Service -Name "postgresql-x64-18" -StartupType Automatic`。

## 8. 常见问题

| 问题 | 原因 / 解决 |
|---|---|
| `python` 打开微软商店 | Windows 别名。用 venv 的 Python：`.\venv\Scripts\python.exe`。 |
| 无法识别 `psql` | 不在 PATH。用完整路径 `C:\Program Files\PostgreSQL\18\bin\psql.exe`。 |
| 数据库连接错误 | 检查 `.env` 的 `BD_CONTRASENA`，以及服务 `postgresql-x64-18` 是否 *Running*。 |
| `CREATE EXTENSION postgis` 失败 | 未安装 PostGIS，用 Stack Builder 安装。 |
| 端口 8000/5173 被占用 | 关闭旧进程或换端口（`--port` / `vite --port`）。 |
| 浏览器 CORS 报错 | 后端已允许 `http://localhost:5173` 与 `http://127.0.0.1:5173`（见 `app/main.py`）。 |
| 前端字体/图标不显示 | 需要网络加载 Google Fonts + Material Symbols，或浏览器缓存后可用。 |
| 管理员登录失败 | 确认已运行 `crear_admin.py`。密码区分大小写。 |
