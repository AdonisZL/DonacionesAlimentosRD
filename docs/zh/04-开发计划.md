# 04 — 开发计划（分阶段）

原则：**分阶段推进，小步且可验证**。当前阶段未验证不进入下一阶段。外部服务在拿到凭证前一律**模拟**。

> 与 [docs/es/04-plan-desarrollo.md](../es/04-plan-desarrollo.md) 对应。

## 阶段 0 — 地基（骨架 + 数据库）
**目标**：前端、后端、数据库连通。
- 检查 PostgreSQL + PostGIS。
- 创建数据库并运行 SQL 脚本（22 张表）。
- 插入种子数据：`roles`（donante、receptor、banco_alimentos、administrador）、`categorias_perecibilidad`（RN-05 窗口）、`categorias_alimentos`。
- 后端：`requirements.txt`、数据库连接、带 `.env` 的 `config`、测试端点（读取 `roles`）。
- 前端：清理模板，安装 router/axios，做能调用后端的首页。
- **验证**：页面显示从数据库读到的数据。

## 阶段 1 — OE1 注册与认证（RF-01…08）
- `usuarios`、`roles`、`perfiles_legales`、`direcciones_sedes` 的模型与模式。
- 注册（正式/特殊捐赠者、接收方、银行），bcrypt ≥ 12 哈希。
- JWT 登录；邮箱验证（模拟）；密码找回（令牌 15 分钟，模拟）。
- 注册时记录 Ley 172-13 同意（RF-31）。
- 前端：注册、登录、个人资料页；保存会话。
- **验证**：注册账号、登录、编辑资料。

## 阶段 2 — OE2 库存与 FEFO（RF-09…16）
- `productos`、`lotes_inventario`、`mermas`、`historial_estado_lote` 模型。
- 批次登记、易腐性分类、窗口计算、窗口 ≤ 0 拒收。
- FEFO 排序库存视图；≤ 3 天预警；手动调整需原因（银行）。
- **验证**：登记批次并看到 FEFO 排序与预警。

## 阶段 3 — OE3 匹配（RF-17…22）
- PostGIS 按可配置半径查询；容量与冷链规则。
- Gemini AI 说明**模拟**；人工确认；重新分配；通知。
- **验证**：给出匹配建议并人工确认。

## 阶段 4 — OE4 报表（RF-23…27）
- 带筛选的捐赠/库存/分配报表。
- Google Sheets 与 DGII PDF 导出**模拟**（本地文件）。
- **验证**：生成并下载报表。

## 阶段 5 — OE5 安全与管理（RF-28…32）
- 端点与视图的 RBAC；审计（bitacora_auditoria）；失败次数锁定。
- 同意管理与 ARCO 请求；管理面板（KPI）。
- **验证**：按角色权限、审计记录、面板可用。

## 后续阶段（MVP 之外）
- 真实集成（Gemini、Sheets、SMTP 邮件、Leaflet 地图）。
- 负载测试（k6/JMeter）、OWASP ZAP 审计、达到测试覆盖目标。
