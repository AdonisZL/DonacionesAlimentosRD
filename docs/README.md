## Cómo usar / 如何使用

- **Antes de programar / 编码前**: leer Requisitos, Arquitectura y Estándares de código. / 阅读需求、架构与代码规范。
- **Al diseñar pantallas / 设计界面时**: seguir la Guía de diseño. / 遵循设计规范。
- **Para avanzar / 推进时**: seguir el Plan de desarrollo por fases. / 按开发计划分阶段推进。
- **Siempre / 始终**: cumplir las reglas de Seguridad. / 遵守安全规范。
